# 1C Release Checker Bot 🤖🚀

**Telegram-бот для автоматического мониторинга выхода новых релизов конфигураций 1С** с официального портала [releases.1c.ru](https://1c.ru). 

Бот самостоятельно парсит страницы обновлений, сравнивает актуальные версии с установленными в вашей базе данных и оперативно отправляет уведомления в Telegram.

---

## ✨ Основные возможности

* **Авторизация с обходом CSRF:** Автоматический вход на портал 1С без участия пользователя.
* **Умный парсинг:** Сбор актуальных версий конфигураций напрямую из HTML-таблиц портала.
* **Интерактивное меню:** Удобное управление подписками (добавление, просмотр, удаление) через инлайн-кнопки в Telegram.
* **Настойчивые уведомления:** Периодические напоминания об обновлениях до тех пор, пока вы не подтвердите установку новой версии.
* **Многопользовательский режим:** Поддержка списка ID администраторов для отправки уведомлений.
* **Быстрый запуск:** Полная контейнеризация проекта с помощью Docker и Docker Compose.

---

## 🛠 Установка и запуск

Для работы бота на сервере должны быть установлены **Docker** и **Docker Compose**.

### 1. Клонирование репозитория

```bash
git clone https://github.com
cd 1c-update-bot
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта и заполните его по следующему шаблону:

```env
# --- Учетные данные портала 1С ---
1C_USERNAME=ваш_логин_1С
1C_PASSWORD=ваш_пароль_1С

# --- Настройки Telegram-бота ---
# Токен бота, полученный у @BotFather
TG_BOT_TOKEN=123456789:AAH...

# ID пользователей, которым разрешен доступ к боту (через запятую, без пробелов)
# Узнать свой ID можно у бота @userinfobot
TG_ADMIN_ID=123456789,987654321

# --- Настройки планировщика ---
# Интервал проверки обновлений (в часах)
CHECK_INTERVAL_HOURS=1
```

### 3. Запуск контейнеров

Выполните команду для сборки и запуска бота в фоновом режиме:

```bash
docker compose up -d --build
```

Для просмотра логов в реальном времени используйте:

```bash
docker compose logs -f
```

## 📱 Инструкция для пользователей

После запуска бота найдите его в Telegram и отправьте команду `/start`.

### Управление подписками
* **Добавить конфигурацию:** Нажмите кнопку в меню. Отправьте боту ссылку на продукт (например, `https://1c.ruproject/AutoService30`) или его точное наименование. Затем укажите текущую версию вашей базы (например, `3.0.14.115`).
* **Мои подписки:** Выводит список всех отслеживаемых конфигураций и их текущий статус (`Актуально` / `Требует обновления`).
* **Удалить подписку:** Позволяет в один клик отписаться от обновлений ненужного продукта.

### Работа уведомлений
Когда на сайте 1С выходит новый релиз, бот присылает сообщение с номером новой версии. Бот будет периодически напоминать об обновлении с заданным интервалом. Напоминания прекратятся только после того, как вы нажмете кнопку **«Я установил эту версию»** под сообщением — после этого локальный статус обновится.

| Файл / Папка | Описание |
| :--- | :--- |
| `main.py` | Основной скрипт: логика бота, хэндлеры, парсер и авторизация. |
