# 1C Release Checker Bot

Telegram-бот для автоматического мониторинга выхода новых релизов конфигураций 1С с официального портала `releases.1c.ru`. Бот выполняет парсинг страниц обновлений, сравнивает актуальные версии с установленными в базе пользователя и отправляет уведомления в Telegram.

## Основные возможности

- Автоматическая авторизация на портале 1С с обходом CSRF-защиты.
- Парсинг актуальных версий конфигураций из HTML-таблиц.
- Интерактивное меню в Telegram для добавления, просмотра и удаления подписок.
- Периодические напоминания об обновлениях до момента подтверждения установки пользователем.
- Поддержка нескольких получателей уведомлений (настраивается через переменные окружения).
- Полная контейнеризация (Docker + Docker Compose).

---

## Установка и запуск

Для работы бота требуются установленные Docker и Docker Compose.

### 1. Клонирование репозитория
```bash
git clone https://github.com/ваш_аккаунт/1c-update-bot.git
cd 1c-update-bot
2. Настройка переменных окружения
Создайте файл .env в корне проекта на основе примера ниже и заполните его своими данными:

env
# Учетные данные портала 1С (releases.1c.ru)
1C_USERNAME=ваш_логин_1С
1C_PASSWORD=ваш_пароль_1С

# Токен Telegram-бота (получить у @BotFather)
TG_BOT_TOKEN=123456789:AAH...

# ID пользователей Telegram, которым разрешено пользоваться ботом и получать уведомления.
# Можно указать несколько через запятую (без пробелов).
# Узнать свой ID можно у бота @userinfobot.
TG_ADMIN_ID=123456789,987654321

# Интервал проверки обновлений в часах
CHECK_INTERVAL_HOURS=1
3. Запуск контейнера
Выполните в терминале:

bash
docker compose up -d --build

Логи работы бота можно посмотреть командой:

bash
docker compose logs -f

Инструкция для пользователей
После запуска бота найдите его в Telegram и отправьте команду /start.

Управление подписками
Добавить конфигурацию: Нажмите соответствующую кнопку в меню. Отправьте боту ссылку на продукт (например, https://releases.1c.ru/project/AutoService30) или просто его имя. Затем укажите вашу текущую версию (например, 3.0.14.115).

Мои подписки: Показывает список отслеживаемых конфигураций и их статусы (Актуально / Требует обновления).

Удалить подписку: Позволяет прекратить отслеживание ненужного продукта в один клик.

Уведомления
Когда на сайте 1С выходит новый релиз, бот присылает сообщение с номером новой версии. Бот будет периодически напоминать об обновлении (с интервалом, заданным в настройках) до тех пор, пока вы не нажмете кнопку «Я установил эту версию». После подтверждения статус обновляется, и напоминания прекращаются.

### Структура проекта
main.py — основной скрипт бота (логика, хэндлеры, парсер, авторизация).

Dockerfile — инструкция для сборки Docker-образа.

docker-compose.yml — конфигурация для запуска контейнера.

requirements.txt — список Python-зависимостей.

.env — файл с секретными данными (не загружается в репозиторий).

1c_data/ — папка для хранения базы данных подписок (создается автоматически).

Безопасность
Файл .env содержит конфиденциальные данные и добавлен в .gitignore. Никогда не публикуйте его в открытых репозиториях.
